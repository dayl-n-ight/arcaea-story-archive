## 解禁方法

### 移动版
- Beyond前置条件：在世界模式失落章，地图获得
• **Present**：通关 Memory Forest PRS；80 残片
• **Future**：以「A」或以上成绩通关 Memory Forest FTR；180 残片

### Nintendo Switch版
• **Past**：游玩 Memory Forest PST；25 残片
• **Present**：游玩 Memory Forest PRS；50 残片
• **Future**：以「AA」或以上成绩通关 Memory Forest FTR；75 残片

### 无情的挑战
解锁搭档露娜所在的地图2-3需要通过本曲的挑战，即“无情的挑战”。

挑战需要使用6级以上的爱托作为搭档游玩本曲，在1:06处（即人声采样“If You Can”的位置），露娜将出现，此后的Drop段（1:06-1:29）轨道消失，此段音符流失数应不超过某一数值（详情见下）。
- 挑战开始前会判断玩家当前的潜力值，若潜力值小于5则可以使用Past难度游玩，小于10则可以使用Present难度游玩，大于等于10则必须使用Future难度游玩。
- 如果挑战合格，谱面轨道在1:29处还原，但背景的露娜不会消失；如果挑战不合格，背景的露娜将会中途消失，谱面轨道提前还原。
- 游玩完成本曲并挑战合格后，地图即可解锁，无需Track Complete。
- 采用达到10级的露娜游玩本曲除Beyond难度外任意难度时亦可触发该挑战~~(无潜力值限制)~~[^1]，且容错随等级的增长与爱托相同。
  - 在本曲Beyond难度刚刚上线时，采用达到10级的露娜游玩本曲Beyond难度仍可触发该挑战，由于Beyond难度采用了与其他难度不同的音源，而异象的触发时间并未跟随改变，因此会出现异象与谱面不契合的情况，该bug之后在3.12.3版本中被修复。
- 解锁Testify后，采用达到6级的爱托游玩本曲除Beyond难度外任意难度时亦可触发该挑战，但仍然具有潜力值限制。
- 在世界模式除Beyond章节外的地图中，使用达到10级的露娜或在解锁Testify后使用达到6级的爱托游玩本曲前三难度仍旧可触发该挑战异象，但在Beyond章节中不会触发。

## 游戏相关

- 本曲的封面可以与Memory Forest的封面组成一张完整的图片（Memory Forest 为左，Singularity 为右）：<table><tr><td>![Songs_memoryforest.jpg](images/Songs_memoryforest.jpg)</td><td>![Songs_singularity.jpg](images/Songs_singularity.jpg)</td></tr></table>
- 在v3.0.0大幅改标等级之前，本曲目为PST 4，PRS 7，FTR 9+。
- 在v5.4.0大幅改标7级及8级的等级之前，本曲PRS难度的定级为7级。
- 本曲标题在被音游收录的曲目中重名率较高。
  - 除本曲以外，keisei(feat. 初音ミク)、technoplanet、xi、Jun Kuroda和Jorts也各有一首名为Singularity的曲目，分别收录于Groove Coaster、O.N.G.E.K.I.、Jubeat、Orzmic和vivid/stasis。
    - 除去上文中technoplanet的Singularity, 在O.N.G.E.K.I.中还另有一首来自世嘉旗下的麻将游戏《セガNET麻雀 MJ（世嘉NET麻雀 MJ）》，由SEGA SOUND STAFF作曲的Singularity, 其作为2021年的愚人节曲目收录。
    - Jun Kuroda的Singularity甚至还和本曲撞了BPM。
- 本曲FTR难度谱面的定数在v3.0.0之前为10.4，是广大玩家眼里的诈称(虚低)；v3.0.0更新后FTR难度谱面定数改为10.7，又被玩家社群当作逆诈称(虚高)。直至v6.0.0更新后FTR难度谱面定数改为10.5，玩家社群才终于开始认可本曲FTR难度谱面的定数。
- 作为五周年庆更新内容的一部分，本曲于v3.12.2追加了Beyond难度(使用愚人节音源)。
- 本曲BYD难度谱面初推出时定数为10.3（v4.0.0改为10.4），低于FTR难度谱面的10.7（v6.0.0改为10.5），是第一个定数低于Future谱面定数的Beyond谱面。
- 本曲BYD难度谱面中出现了常驻谱面中的第一个伪五押配置（4长条+1蛇），但是只需要用两根手指单点长条头判然后单指划蛇即可，并非真正的五押。
- 本曲FTR难度谱面在v6.0.0进行了调整，其原先的谱面中部分天地双押的判定区域出现了重叠，由于判定优先级的机制导致游玩时较易出现Lost的情况，此次改谱调整了这部分天地双押的间距。
- 因联动收录至Groove Coaster和O.N.G.E.K.I.。
  - 上文中提到Groove Coaster中已存在同名曲目，故收录本曲时在曲名后加上了Arcaea侧的曲包名“-Binary Enfold-”以区分这两首曲目。
  - Groove Coaster的背景动画还原了该曲目的背景和谱面甚至是If you can段中露娜的剪影。
  - O.N.G.E.K.I.的谱面中含有形如“If U Can”的弹幕。

## 攻略

此章节可能包含主观内容。

**Beyond 10**

- 轴交互练习曲(一手天键一手地键)
- 83combo开始的所有轴交互均为天键起手
- 271combo开始的音弧判定较严，且跨度较大
- 342combo与qualia -ideaesthesia- BYD类似，需借助音弧的判定来接住长条，音弧请滑到尾再换手，不然容易漏
- 462-463,467-468combo双押出张较大，可考虑用多指
- 477combo以后的音弧需注意划到每个拐角
- 812combo开始的天键交互部分出张较大，如果不考虑准度可使用接地键的手进行硬抗天键的最后一个键
- 最后一小段交互是右起手


**Future 10**

- 本谱最大特色为中间对短时间快速连点、位移和玩蛇功底有很高要求的"If you can"段
  - 同时，本谱中也有各式各样的天地交互，其中有不少还带有出张
- 105combo后的第一段交互为左起手上下分层；第二段交互为右起手，两手运动轨迹呈直角三角形
  - 此配置的镜像及变种在全曲多次出现
  - 比如769combo(即刚出"If you can"段)就出现了此配置的变种，此段的上下分层带有出张
  - 注意:"if you can"段后的天地交互与前面的一段指法不同，运动轨迹似乎不同
- 280combo左右的双押有手序引导，打起来很舒服
  - 947combo的就没有引导了，此处双押的出张幅度很大，如果正攻接不来可以考虑多指处理或反接音弧
- 422\~429的配置是双押-单点-双押-双押，注意天键位置
  - 442\~449同理
- If you can段的音弧扭动幅度非常大，基本都是贴着判定区的边缘
  - 此段结尾的交互是左起手16分转24分
- 909combo起的左手地-天-地-天中地键不要点太高，938combo同理
- 1046combo的天地混fr可以试试上下分层处理
- 全曲最后的天地交互是左起手
