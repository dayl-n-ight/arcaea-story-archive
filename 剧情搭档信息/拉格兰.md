## 技能
> **技能：** 当前分数将显示为与距离最近评级的分数之差
- 技能生效条件为完成Aegleseeker的初始异象，技能生效前原技能显示处显示为`游玩《Aegleseeker》`。
  - 这里使用的是“生效”而不是“解锁”是因为服务器端不会记录技能是否可用，如果更换一个未完成异象的本地设备，这个技能会重新变为未生效状态。
- 具体效果是将游戏界面右上角的分数更改为技能描述的差值和离分数最近的评级，同时分数栏中的“Score”字样变为“Pace”。
  - 初始评级为“PM”(即Pure Memory，等价于10,000,000分，详见计分方式相关内容)，初始分数为+0。
  - 在游玩过程中，根据当前位置的总分确定每个评级的基准分数，再根据当前游玩的分数计算出与距离最近的评级基准分数的差值，显示为分数栏处的分数。
    - 并不是所有情况下都是距离最近的评级，具体规则与举例见具体算法。
  - 仅影响游戏当中的分数显示，结算界面显示的分数为通常分数。
- 本质为视觉系技能。
### 具体算法

```
当前总分 = 当前经过的note总数 &divide; 谱面总note数 &times; 10,000,000
```

```
基准分数 = 当前的总分 &times; 基准分数占比
```

```
显示分数 (即与评级基准的分数差) = 当前实际分数 &minus; 基准分数
```

根据当前实际分数与当前总分的比值所处的区间确定当前评级与基准分数：

| 当前分数占比区间 | 当前评级 | 基准分数占比 |
|------|------|------|
| ≥100% | PM | 100% |
| ≥99% | EX+ | 99% |
| ≥96.5% | EX | 98% |
| ≥93.5% | AA | 95% |
| ≥90.5% | A | 92% |
| ≥87.5% | B | 89% |
| <87.5% | C | 86% |

;举例：
- 假设当前位置总分为3000000，则EX+评级基准分数为3000000&times;99%=2970000，EX评级基准分数为3000000&times;98%=2940000，以此类推，在此情况下：
  - 假设当前分数为3000275，以PM（3000000）为基准评级，显示为+000275 PM
  - 假设当前分数为2935260，以EX（2940000）为基准评级，显示为-004740 EX
  - 假设当前分数为2235205，以C（2580000）为基准评级，显示为-344795 C
  - 假设当前分数为1000000，以C（2580000）为基准评级，计算得到-1580000，但由于此时分数显示只有六位，实际显示为-999999 C
- 因此刚开始游戏时会出现打出几个far评级基准就会很快掉到AA而以后lost几个也不容易掉级的原因，算法类似于别的音游中的“ACC”。
- v3.8.2前曾存在一种特殊情况：当前经过的note全部为小P时，理论上当前实际分数等于当前总分，但由于实际分数不保留小数位，会算得占比区间<100%，按照EX+评级计分。
  - 此情况在v3.8.2更新后已修改，当经过的note全部为小P时，将算得占比区间=100%，显示为+000000 PM
## 搭档相关
- 该搭档在游戏中拥有自己的故事，详见故事模式。
- 该搭档的英文名和日文名均为“拉格朗日”(Lagrange / ラグランジュ)。
  - 其立绘的服装上写有一行文字“Joseph-Louis Lagrange”，据此可推测其设计原型可能为数学家、物理学家兼天文学家拉格朗日。
- 该搭档身旁的随从名为“卡戎”(Charon)，这也是冥卫一的名字。
  - 该随从上标有一行文字“S/1978P1”，此编号是冥卫一最初被发现时的天文学编号。
- 以下曲目的曲绘出现了拉格兰的形象:
- Far Away Light
- Aegleseeker
- Seclusion
- Divine Light of Myriad
