……所以，摩耶貌似希望她的想法被别人所知？看起来她的确有所成长。
 
……那便如此吧。
 
看来，摩耶不仅想起了自从她在Arcaea醒来后所发生的一切，她还想起了在那之前所发生的一切。
 
她想起了她已经失去的所有从前的朋友。

----
其中的一个记忆：
一本小小的纸质书：没落于时代和社会的进步，但她就是喜欢那种特别的触感——况且对她来说，“小众”
和“不同”反而是加分项。在十二岁的小小年纪，她便享受着军装给她带来的与众不同的快感。她对自己
的很多方面感到十分得意——但阅读纸质书能给她带来的满足感绝非是随便一件小事就能与其相比的。有
一天她正坐在靠椅上读着书时，她的朋友不禁问道：
 
“你到底都是从哪里弄来这些东西的？”
 
一间小店，一个老人家，店里那些上了年头的东西……她想起来了。
 
可她还是无法永远记得。于是，她最终还是遗忘了这一切；于是，她再次站起身，继续在这个世界上行走。

----
日子一天天过去，日志中布满字迹的页面也一张张变多。起初，这些都是关于她的故事：从第一次生命，
到第二次生命，再到这里。然后之后的最后几条记录却与她在神殿中遇到的种种奇特的奥秘有关……
 
//摩耶，捌。//
 
// 现在我想，即使自己再不情愿，再感到恼火，我也不得不接受魔法真的可能是存在的这一事实了。
 
如果这不叫魔法的话，叫它能量的奇迹也可以，它甚至可以是“神明”的神力所现——
 
诡异的通道、近乎可见但仍无法感知到的幻影、凭空悬吊在半空的灯光，以及这个地方难以置信的面积——
它甚至或许还在不断扩展。//

----
//——我无法轻易相信来世。
我已死去，这点完全是肯定的。我知道我那时的感受，也知道这一切都是我的错。
考虑到这一点，以及我的死亡——
 
考虑到我照镜子时看到的完全陌生的面孔和双眼——
这是一个简单的事实：我现在看起来与生前大不相同了。
可这一切都好似于事无补，因为我最初写下的记忆已经开始从我的脑海中消逝。//

----
// 如果将我困住我的那个女人并非如她所言——是所谓的「神」，那她会不会是一个扭曲的天使？她会不
会是死神？那可真是恶毒啊。
 
这里难道就是她的家？可这里为什么没有任何印着她自己样貌的照片或肖像？
 
而且，如果这便是来世，那 //
 
她停下了笔。她从日记本上抬起头，透过头顶上方的一扇小小的圆形窗户望去。
 
她不禁想……
如果这真的是「来世」……
如果我没有就那样孤独地死去……
 
我会不会就不会像现在这样孤独地来到这里？
如果我并不是孤独地死去，我的“声音”说不定早已布满了星辰。

----
……她曾经是军人，曾经是“读心者”。没错，她曾经跟许多人都建立了所谓的链接——但他们最终都
死去了。
 
因此现在……
她眯起眼睛，将目光只聚焦在上方的窗户上，在心里朝远处的天穹呼唤。
 
一个信号，一则讯息，犹豫但清晰：“有人在吗？”

----
这回，有什么人的声音回答了。
 
是一个少女的声音，自她的骨髓深处轻轻响起：


“我……我在。你、你是谁……？”
