# Arcaea 故事模式剧情档案

Arcaea 故事模式及相关内容的本地化存档，覆盖故事剧情、搭档信息、剧情关键歌曲。

## 基本概念

| 概念 | 是什么 | 载体 |
|------|--------|------|
| **故事** | 叙事容器，分 Act → Part → 类型 → 故事名称 四级 | 目录树 + `剧情结构说明.md` |
| **剧情** | 最小叙事单元，190+ 个编号小节 | `zh/` `en/` 下的 `.md` 文件 |
| **人物** | 叙事层面的角色（光、对立、红……） | 搭档名去掉后缀即是 |
| **搭档** | 人物在玩法侧的形态，一个人物可有多个 | `剧情搭档信息/`下的 `.md` 文件 |
| **歌曲** | 推进剧情的钥匙 | `剧情歌曲信息/`下的 `.md` 文件 |

故事、搭档、歌曲在 Arcaea 中是相互耦合的。绝大部分剧情小节的解锁方式都遵循同一个简单模式：
`购入曲包或单曲 → 用指定搭档通关指定歌曲 → 解锁下一段剧情`

```markdown
# 1-4

- **解锁条件**：购入 Luminous Sky 曲包
- **解锁要求**：采用光，通过 Maze No.9
```

每段剧情的`en/{故事ID}.md`或 `zh/{故事ID}.md` 前几行直接给出关联信息。

## 进阶概念

少数歌曲存在特殊的**游玩效果**——异象触发、曲目挑战、游历等。音乐游戏的玩法机制本身成为叙事手段：回忆率归零不中断曲目、暂停键隐藏、背景破碎、UI 雾化……这类效果及其对应的曲目参见 [`游玩效果.md`](游玩效果.md)。

举一个典型的异象链（Luminous Sky 曲包）：

```
光（Zero）→ Ether Strike → [异象触发] → Fracture Ray → 光（Fracture）
    ↓                            ↓                         ↓
  1-ZR                          1-8                       1-9
```

使用**光（Zero）** 游玩 **Ether Strike**，满足条件后触发异象，切入 **Fracture Ray**。通过后获得**光（Fracture）**。每一步解锁一段对应剧情，下一段剧情要求的搭档形态恰好是上一步获得的。

更复杂的分支结局参见 Last 的「解禁方法」（同一首歌的两个选择通向完全不同的结局和搭档）。

## 目录

```
├── Act I Creation/             # 第一幕：各章节剧情正文（zh + en）
│   ├── Part I/                 #   按曲包分目录
│   ├── Part II/                
│   └── Part III/               
├── Act II Catastrophe/         # 第二幕
├── 剧情搭档信息/               # 各搭档档案 + 立绘
├── 剧情歌曲信息/               # 剧情关键歌曲档案 + 曲绘
├── 故事模式构成与流程.md       # 故事模式整体架构，角色与故事的对应关系
├── 剧情结构说明.md             # 剧情数据结构，ID 规范、icon→路径映射
├── 剧情目录树.md               # 完整文件树索引，按照游戏默认顺序排列
├── 游玩效果.md                 # 异象、挑战、游历等特殊游玩效果
├── LICENSE.md                 # 许可与来源
└── README.md
```

## 快速查询

| 你想知道 | 去哪儿看 |
|---------|---------|
| 某段剧情用哪个搭档、哪首歌解锁 | `zh/{故事ID}.md` 前三行 |
| 某首歌的异象/挑战怎么触发 | `剧情歌曲信息/{曲名}.md` 的「解禁方法」 |
| 故事的分类与顺序 | [`故事模式构成与流程.md`](故事模式构成与流程.md) |
| 一个故事内节的解锁顺序 | [`剧情目录树.md`](剧情目录树.md) |
| 有哪些角色，某个故事的主角是谁 | [`故事模式构成与流程.md`](故事模式构成与流程.md) |
| 有哪些特殊游玩效果的曲目 | [`游玩效果.md`](游玩效果.md) |
| 剧情数据是怎么从wiki中提取出来的 | [`剧情结构说明.md`](剧情结构说明.md) |
| 快速获取各个故事剧情结构印象 | [`剧情结构说明.md`](剧情结构说明.md) |
| 某首歌属于哪个故事 | 在 `Act I Creation/` 或 `Act II Catastrophe/` 下搜索该曲名，或在`剧情歌曲信息/{曲名}.md`的「曲包」 |
| 某个搭档有什么能力，与哪些歌曲有关系 | 在 `Act I Creation/` 或 `Act II Catastrophe/` 下搜索该搭档名阅读上下文，或`剧情搭档信息/{搭档名}.md` 的「技能」「搭档相关」 |
| 某首曲绘中有哪些搭档 | `剧情搭档信息/` 下搜索该曲名 |
